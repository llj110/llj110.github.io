03 / THE METHOD

Trust the evidence. Preserve the memory.衡量观测可靠性，保留稳定场景记忆。

State Innovation Gating

SIG references the initial geometric state when assessing an innovation. It provides an explicit control on how the recurrent representation evolves as a video becomes longer.SIG 以初始几何状态为参考评估状态创新，为长视频中的循环表示变化提供显式控制。

Bayesian-guided Adaptive State Updating

BASU tracks historical reliability and weights new evidence using observation confidence and cross-attention relevance. Temporal informativeness and spatial applicability guide selective state updates.BASU 跟踪历史状态可靠性，结合观测置信度与交叉注意力相关性衡量新证据，并利用时间信息量与空间适用性引导选择性状态更新。

Read the research overview阅读研究概述

Streaming 3D reconstruction compresses a video's history into a recurrent scene state, enabling continuous spatial perception without retaining every past frame. This compact memory can accumulate errors when observations differ in reliability. BAT3R addresses this through Bayesian test-time adaptation: SIG regularizes state evolution around its geometric initialization, and BASU combines explicit beliefs about state reliability with observation-side confidence and cross-attention relevance. The method is evaluated on scene reconstruction, camera pose estimation, and video depth estimation.流式三维重建将视频历史压缩为循环场景状态，无需保存全部历史帧即可持续进行空间感知。但不同观测的可靠性差异可能导致紧凑记忆积累误差。BAT3R 通过贝叶斯测试时适应处理这一问题：SIG 围绕几何初始化调节状态演化，BASU 将状态可靠性信念与观测置信度、交叉注意力相关性相结合。评估任务覆盖场景重建、相机位姿估计和视频深度估计。

Run your own reconstruction重建自己的视频

Once you have the source and a compatible starting checkpoint, the inference entry point accepts a video or image directory.获得源码及兼容的初始化检查点后，推理入口可处理视频或图像文件夹。

python bat3r_demo.py \
  --model_path /path/to/cut3r_512_dpt_4_64.pth \
  --seq_path /path/to/video.mp4 \
  --model_update_type bat3r --size 512 \
  --output_dir outputs/my_scene

The upstream CUT3R model is a starting checkpoint. Exact checkpoints and configurations for paper-level reproduction should follow the released experiment documentation.上游 CUT3R 模型作为初始化检查点；论文级复现请遵循发布的实验检查点与配置说明。
