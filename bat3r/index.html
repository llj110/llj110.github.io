03 / THE METHOD

Method overview.方法概览。

The architecture from the paper: State Innovation Gating anchors recurrent updates, and Bayesian-guided Adaptive State Updating fuses historical uncertainty with new evidence.论文主架构图：State Innovation Gating 约束循环状态更新，Bayesian-guided Adaptive State Updating 融合历史不确定性与新观测证据。

State Innovation Gating (SIG)

Anchor the recurrent state to its geometric initialization to regulate drift over extended sequences.以几何初始化为锚点，约束长序列中的循环状态漂移。

Bayesian-guided Adaptive State Updating (BASU)

Combine historical state uncertainty, observation confidence, and spatial relevance for selective state updates.结合历史状态不确定性、观测置信度和空间相关性，选择性地更新场景状态。

Run your own reconstruction重建自己的视频

Once you have the source and a compatible starting checkpoint, the inference entry point accepts a video or image directory.获得源码及兼容的初始化检查点后，推理入口可处理视频或图像文件夹。

python bat3r_demo.py \
  --model_path /path/to/cut3r_512_dpt_4_64.pth \
  --seq_path /path/to/video.mp4 \
  --model_update_type bat3r --size 512 \
  --output_dir outputs/my_scene

The upstream CUT3R model is a starting checkpoint. Exact checkpoints and configurations for paper-level reproduction should follow the released experiment documentation.上游 CUT3R 模型作为初始化检查点；论文级复现请遵循发布的实验检查点与配置说明。
